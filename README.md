Contabo GmbH is a German hosting provider offering VPS, VDS, dedicated and GPU servers, S3-compatible object storage, private networking, DNS and domains. The Contabo API (https://api.contabo.com, OpenAPI 3.0.3, 157 operations) manages compute instances, snapshots, images, object storage, private networks, secrets, users, roles and tags using OAuth2 password-grant bearer tokens from auth.contabo.com; Contabo also ships the cntb CLI and a Terraform provider.

**Areas:** Company · Cloud Hosting · VPS · Object Storage · Infrastructure · Dedicated Servers · DNS

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Contabo: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
